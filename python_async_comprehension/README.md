# Python - Async Comprehension

Asynchronous generators and comprehensions in Python.

## Description

An async generator that yields random numbers with a delay, an async
comprehension that collects them, and a coroutine that measures how long
four of those comprehensions take when gathered in parallel.

## Topics

- Writing asynchronous generators
- Async comprehensions with `async for`
- Running coroutines in parallel with `asyncio.gather`
- Type-annotating async code
