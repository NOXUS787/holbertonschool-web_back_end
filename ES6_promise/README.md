# ES6 Promises

This project covers JavaScript promises: creating them, resolving and
rejecting them, chaining with `then`, `catch` and `finally`, and combining
them. It uses Jest for tests and ESLint (Airbnb rules) for linting.

## Files

| File | Description |
| --- | --- |
| `0-promise.js` | `getResponseFromAPI` returns a Promise. |
| `1-promise.js` | `getFullResponseFromAPI` resolves with a success object or rejects with an error. |
| `2-then.js` | `handleResponseFromAPI` handles a promise with `then`, `catch` and `finally`. |
| `3-all.js` | `handleProfileSignup` resolves `uploadPhoto` and `createUser` together with `Promise.all`. |
