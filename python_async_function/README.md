# Python - Async

Asynchronous programming in Python with async, await, and asyncio.

## Description

Coroutines that wait for random delays, run concurrently, and are
wrapped in asyncio tasks, along with a helper that measures the average
runtime of concurrent execution.

## Topics

- async and await syntax
- Running an async program with asyncio.run
- Executing coroutines concurrently
- Creating asyncio tasks
- Generating random values with the random module
