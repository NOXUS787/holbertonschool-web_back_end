# ES6 Data Manipulation

This project covers working with data in ES6: `map`, `filter` and `reduce`
on arrays, typed arrays, and the `Set`, `Map` and `WeakMap` data structures.
It uses Jest for tests and ESLint (Airbnb rules) for linting.

## Files

| File | Description |
| --- | --- |
| `0-get_list_students.js` | `getListStudents` returns an array of student objects. |
| `1-get_list_student_ids.js` | `getListStudentIds` returns the ids of a list of students using `map`. |
| `2-get_students_by_loc.js` | `getStudentsByLocation` returns the students in a given city using `filter`. |
| `3-get_ids_sum.js` | `getStudentIdsSum` returns the sum of all student ids using `reduce`. |
| `4-update_grade_by_city.js` | `updateStudentGradeByCity` returns the students of a city with their new grade, using `filter` and `map`. |
| `5-typed_arrays.js` | `createInt8TypedArray` returns a `DataView` over a new buffer with an `Int8` value at a position. |
