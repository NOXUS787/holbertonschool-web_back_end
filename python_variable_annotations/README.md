# Python - Variable Annotations

Type annotations in Python 3, function signatures, duck typing, and
validating code with mypy.

## Description

Annotated functions and variables demonstrating how Python's typing
system documents intent without changing runtime behavior.

## Requirements

- Python 3.9 on Ubuntu 20.04 LTS
- Every file begins with the env python3 shebang and is executable
- Code follows pycodestyle 2.5
- All modules, classes, and functions are documented
