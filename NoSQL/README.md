# NoSQL

This project covers NoSQL databases and how to use MongoDB: querying,
inserting, updating and deleting documents from the mongo shell and from
Python with PyMongo.

## Files

| File | Description |
| --- | --- |
| `0-list_databases` | Mongo shell script that lists all databases. |

## Requirements

- Ubuntu 20.04 LTS, MongoDB 4.4
- Python scripts use Python 3.9, PyMongo 4.8.0 and `pycodestyle` 2.5.*
- The first line of each MongoDB command file is a comment (`// my comment`)
