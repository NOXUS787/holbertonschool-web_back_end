# ES6 Basics

This project covers the basics of ES6: const and let, block-scoped
variables, arrow functions, default and rest parameters, string templates,
object creation and iterators, with Jest tests and ESLint (Airbnb rules).

## Files

| File | Description |
| --- | --- |
| `0-constants.js` | Uses `const` in `taskFirst` and `let` in `taskNext`. |
| `1-block-scoped.js` | Block-scoped `const` so the conditional block does not overwrite the outer variables. |
| `2-arrow.js` | Rewrites `addNeighborhood` as an arrow function that uses the lexical `this`. |
| `3-default-parameter.js` | Uses default parameter values instead of manual `undefined` checks. |
| `4-rest-parameter.js` | Uses the rest parameter syntax to count the arguments passed to a function. |
| `5-spread-operator.js` | Uses spread syntax to concatenate two arrays and the characters of a string. |
| `6-string-interpolation.js` | Builds a description with a template literal instead of string concatenation. |
| `7-getBudgetObject.js` | Builds an object with the property value shorthand syntax. |
| `8-getBudgetCurrentYear.js` | Builds the budget object with ES6 computed property names. |
| `9-getFullBudget.js` | Defines the budget methods with the ES6 method property shorthand. |
| `10-loops.js` | Rewrites a `for...in` loop with `for...of` and `const`. |
| `10-loops.js` | Rewrites a `for...in` loop with `for...of` and `const`. |
| `11-createEmployeesObject.js` | Returns an object keyed by a computed department name that holds the employees. |
